## 使用说明

### 1. 素材放置位置
- 图片素材：`entry/src/main/resources/rawfile/images/`
- 视频素材：`entry/src/main/resources/rawfile/videos/`
- 音频素材：`entry/src/main/resources/rawfile/audios/`

### 2. 素材引用方式
```typescript
// 图片
$r('app.media.emotion_frames_heal_001')

// 视频和音频（rawfile方式）
$rawfile('videos/emotion_videos/heal_001.mp4')
```

### 3. 素材命名规范
- 使用小写字母和下划线
- 格式：`类别_序号.扩展名`
- 示例：`heal_001.jpg`, `burn_002.mp4`

### 4. 素材获取建议
- 可从免费素材网站下载（如 Pexels, Unsplash）
- 视频素材建议使用短视频片段
- 注意版权问题，使用免费或授权素材
